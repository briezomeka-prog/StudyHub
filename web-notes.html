BBCT 1106

Web Design & Development

Complete study notes covering web technologies, HTML, CSS, JavaScript, responsive design, web development tools, accessibility, security and modern web development concepts.

1. Introduction to Web Design and Development

Web design and development is the process of creating websites and web applications that can be accessed through the Internet or an internal network.

Web design mainly focuses on the appearance, layout and user experience of a website, while web development focuses on the technical implementation and functionality.

Web Design: The process of planning and creating the visual appearance, layout and user experience of a website.
Web Development: The process of building the functional parts of a website using programming and web technologies.

2. The World Wide Web

The World Wide Web, commonly called the Web, is a system of interconnected documents and resources accessed through the Internet using web browsers.

Users can access websites by entering addresses called Uniform Resource Locators (URLs).

Examples of Web Browsers

  • Google Chrome
  • Mozilla Firefox
  • Microsoft Edge
  • Safari
  • Opera

3. Internet and World Wide Web

The Internet is the global network of interconnected computers and devices.

The World Wide Web is one of the services that operates on the Internet.

Remember: The Internet and the World Wide Web are not exactly the same. The Internet is the network, while the Web is a service that uses that network.

4. Client and Server

A client is a device or software application that requests services or information from another computer.

A server is a computer or system that provides services, resources or information to clients.

Example

When you open a website, your browser acts as the client. The web server receives the request and sends the required web files back to the browser.

5. Front-End and Back-End Development

Front-End Development

Front-end development deals with the part of a website that users can see and interact with.

  • HTML
  • CSS
  • JavaScript

Back-End Development

Back-end development deals with server-side operations, databases, authentication and application logic.

Common back-end technologies include PHP, Python, Java, Node.js and C#.

6. HTML

HTML stands for HyperText Markup Language. It is the standard markup language used to structure content on web pages.

Common HTML Elements

  • Headings
  • Paragraphs
  • Links
  • Images
  • Lists
  • Tables
  • Forms

7. Basic HTML Structure

A basic HTML document contains the document type declaration, HTML element, head section and body section. 

<!DOCTYPE html>
<html>

<head>
    <title>My Website</title>
</head>

<body>

    <h1>Welcome</h1>

    <p>This is my website.</p>

</body>

</html>

8. HTML Headings and Paragraphs

HTML provides six heading levels from h1 to h6. The h1 element represents the most important heading. 

<h1>Main Heading</h1>

<h2>Sub Heading</h2>

<h3>Another Heading</h3>

<p>This is a paragraph.</p>

9. HTML Attributes

Attributes provide additional information about HTML elements. They are normally written inside the opening tag.

Example

<a href="about.html">
    About Us
</a>

Here, href is an attribute that specifies where the link should go.

10. HTML Links

Links allow users to move from one page or resource to another. 

<a href="index.html">
    Home
</a>

External Link

<a href="https://www.google.com">
    Visit Google
</a>

11. Images in HTML

Images make websites more attractive and can communicate information visually. 

<img src="photo.jpg"
     alt="Student studying">

The src attribute specifies the image location, while alt provides alternative text.

12. HTML Lists

HTML supports ordered and unordered lists.

Unordered List

<ul>

    <li>HTML</li>
    <li>CSS</li>
    <li>JavaScript</li>

</ul>

Ordered List

<ol>

    <li>Plan</li>
    <li>Design</li>
    <li>Develop</li>

</ol>

13. HTML Tables

Tables are used to display information in rows and columns. 

<table>

    <tr>
        <th>Name</th>
        <th>Course</th>
    </tr>

    <tr>
        <td>John</td>
        <td>Computing</td>
    </tr>

</table>

14. HTML Forms

Forms allow users to enter and submit information.

Common Form Controls

  • Text fields
  • Password fields
  • Email fields
  • Radio buttons
  • Checkboxes
  • Dropdown lists
  • Submit buttons
<form>

    <label>Name:</label>

    <input type="text"
           name="name">

    <button type="submit">
        Submit
    </button>

</form>

15. CSS

CSS stands for Cascading Style Sheets. It is used to control the appearance and presentation of web pages.

CSS Can Control

  • Colors
  • Fonts
  • Spacing
  • Backgrounds
  • Layouts
  • Borders
  • Animations
  • Responsive design

16. Types of CSS

Inline CSS

<p style="color: blue;">
    Hello
</p>

Internal CSS

<style>

p {
    color: blue;
}

</style>

External CSS

<link rel="stylesheet"
      href="style.css">

External CSS is generally preferred for larger websites because it allows multiple pages to share the same styles.

17. CSS Selectors

Selectors identify the HTML elements that CSS rules should style.

Element Selector

p {
    color: blue;
}

Class Selector

.card {
    padding: 20px;
}

ID Selector

#header {
    background: navy;
}

18. CSS Box Model

The CSS box model describes how space is calculated around HTML elements.

  • Content – the actual information.
  • Padding – space inside the element.
  • Border – line surrounding the padding.
  • Margin – space outside the element.
Exam Tip: Remember the order: Content → Padding → Border → Margin.

19. CSS Flexbox

Flexbox is a CSS layout system used to arrange elements in rows or columns. 

.container {

    display: flex;

    justify-content: center;

    align-items: center;

}

Advantages of Flexbox

  • Easy alignment
  • Flexible layouts
  • Responsive arrangement
  • Useful for navigation bars and cards

20. CSS Grid

CSS Grid is a layout system designed for arranging content in rows and columns. 

.container {

    display: grid;

    grid-template-columns:
        repeat(3, 1fr);

    gap: 20px;

}

21. Responsive Web Design

Responsive web design means creating websites that adapt to different screen sizes and devices.

A responsive website should work properly on computers, tablets and mobile phones.

Important Techniques

  • Flexible layouts
  • Responsive images
  • CSS media queries
  • Flexible grids
  • Relative units

22. JavaScript

JavaScript is a programming language commonly used to add interactivity and dynamic behavior to web pages.

Examples

  • Interactive buttons
  • Form validation
  • Menus
  • Animations
  • Calculations
  • Dynamic content
<script>

alert("Welcome to StudyHub");

</script>

23. JavaScript Variables

Variables store information that can be used by a program. 

let name = "John";

let age = 20;

const country = "Uganda";

JavaScript commonly uses let, const and historically var for declaring variables.

24. Document Object Model (DOM)

The Document Object Model represents an HTML document as objects that JavaScript can access and modify.

Using the DOM, JavaScript can change text, styles, attributes and page content. 

document.getElementById("title")
    .textContent = "StudyHub";

25. Web Development Tools

Web developers use different tools to design, develop, test and maintain websites.

  • Visual Studio Code
  • Google Chrome
  • Firefox Developer Tools
  • Git
  • GitHub
  • Image editing tools
Example: Visual Studio Code can be used to write HTML, CSS and JavaScript files.

26. Website File Structure

A simple website may contain several HTML pages, a CSS file, JavaScript files and image files. 

StudyHub/

    index.html
    subjects.html
    notes.html
    style.css
    script.js

    database.jpg
    web-design.jpg
    computer.jpg

Keeping files organized makes websites easier to develop and maintain.

27. Domain Names

A domain name is the human-readable address used to access a website.

Examples

  • google.com
  • wikipedia.org
  • example.edu

A domain name is easier for people to remember than a numerical IP address.

28. Web Hosting

Web hosting is a service that provides storage and resources for website files so that they can be accessed online.

Examples of Hosting Platforms

  • GitHub Pages
  • Netlify
  • Vercel
  • Traditional web hosting services

29. Website Accessibility

Web accessibility means designing websites that can be used by people with different abilities and disabilities.

Important Practices

  • Use meaningful alternative text for images.
  • Use clear headings.
  • Provide keyboard navigation.
  • Use readable text.
  • Maintain good color contrast.
  • Label form controls properly.

30. Web Security

Web security involves protecting websites, users and data from unauthorized access and attacks.

Common Threats

  • Cross-Site Scripting (XSS)
  • SQL Injection
  • Phishing
  • Weak passwords
  • Session attacks
  • Malware

Basic Security Practices

  • Use strong passwords.
  • Validate user input.
  • Keep software updated.
  • Use HTTPS.
  • Protect sensitive information.

31. Website Testing

Testing ensures that a website works correctly and meets its requirements.

Things to Test

  • Links
  • Forms
  • Images
  • Buttons
  • Navigation
  • Mobile responsiveness
  • Browser compatibility
  • Page loading

32. Principles of Good Web Design

A good website should be easy to understand, attractive and simple to use.

  • Consistency: Keep similar design elements consistent.
  • Simplicity: Avoid unnecessary complexity.
  • Navigation: Make important pages easy to find.
  • Readability: Use clear fonts and spacing.
  • Responsiveness: Support different devices.
  • Accessibility: Make the site usable by many people.
  • Performance: Make pages load efficiently.

33. Web Applications

A web application is software that runs through a web browser and usually provides interactive functionality.

Examples

  • Online banking systems
  • Learning management systems
  • Email services
  • Online shopping systems
  • Social media platforms

34. Static and Dynamic Websites

Static Website

A static website mainly displays fixed content and does not usually change based on user interaction or database data.

Dynamic Website

A dynamic website can generate or modify content based on users, databases, server-side logic or other information.

Example: A simple personal portfolio can be static, while an online banking system is dynamic.

35. Full-Stack Development

Full-stack development involves working with both front-end and back-end parts of a web application.

Typical Full-Stack Areas

  • HTML
  • CSS
  • JavaScript
  • Server-side programming
  • Databases
  • APIs
  • Security
  • Deployment

36. Advantages of Web Development

  • Websites can reach users worldwide.
  • Users can access services from different devices.
  • Web applications can be updated centrally.
  • Businesses can provide services online.
  • Educational resources can be shared easily.
  • Web applications can automate many processes.

37. Common Web Development Terms

  • HTML: Structures web content.
  • CSS: Styles web pages.
  • JavaScript: Adds behavior and interactivity.
  • URL: Address of a web resource.
  • HTTP: Protocol used for web communication.
  • HTTPS: Secure version of HTTP.
  • Browser: Software used to access websites.
  • Server: Provides resources or services.
  • Domain: Human-readable website address.
  • Hosting: Service that stores website files.

38. Steps in Developing a Website

  1. Identify the purpose of the website.
  2. Identify the target users.
  3. Gather requirements.
  4. Plan the website structure.
  5. Create the design.
  6. Develop the HTML structure.
  7. Add CSS styling.
  8. Add JavaScript functionality.
  9. Test the website.
  10. Fix errors.
  11. Publish the website.
  12. Maintain and update the website.

39. HTML, CSS and JavaScript Working Together

HTML, CSS and JavaScript have different but complementary roles.

  • HTML provides the structure.
  • CSS controls the appearance.
  • JavaScript provides interaction and behavior.
Simple Example: A button can be created using HTML, styled using CSS, and programmed to perform an action using JavaScript.

A beginner can create a simple student profile website containing the following:

42. Summary

Web design and development involves planning, designing, building, testing and maintaining websites and web applications.

HTML provides structure, CSS provides presentation and JavaScript provides interactivity.

A good website should be attractive, responsive, accessible, secure, easy to navigate and useful to its intended users.

Key Point: To become a good web developer, learn HTML first, then CSS, then JavaScript, while continuously practicing by building real projects.
