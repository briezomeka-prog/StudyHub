BSCT 1112

Programming Concepts Using C

Complete study notes covering C programming fundamentals, variables, data types, operators, control structures, arrays, functions, pointers, structures, file handling and problem-solving.

1. Introduction to Programming

Programming is the process of writing instructions that tell a computer how to perform a particular task.

A programming language provides a way for humans to communicate instructions to computers.

Program: A set of instructions written to solve a particular problem or perform a specific task.

Examples of Programming Languages

  • C
  • C++
  • Python
  • Java
  • JavaScript
  • C#

2. History of Programming

The history of programming began with early mechanical computing machines and developed into modern high-level programming languages.

Early programmers had to work with machine instructions. As computing developed, assembly languages and high-level languages were created to make programming easier.

3. History of the C Programming Language

The C programming language was developed by Dennis Ritchie at Bell Laboratories in the early 1970s.

C was developed from earlier programming languages and became widely used for system programming and software development.

Importance of C

  • It is fast and efficient.
  • It provides low-level memory access.
  • It influenced many later programming languages.
  • It is widely used in system programming.
  • It helps students understand programming fundamentals.

4. Features of C

  • Simple and relatively easy to learn.
  • Structured programming language.
  • Portable between different systems.
  • Efficient and fast.
  • Supports functions.
  • Supports pointers.
  • Provides direct memory manipulation.
  • Supports modular programming.

5. Advantages and Disadvantages of C

Advantages

  • Fast execution.
  • Portable.
  • Efficient use of memory.
  • Large amount of learning material.
  • Useful for system programming.

Disadvantages

  • Does not provide automatic memory management.
  • Pointers can be difficult for beginners.
  • Programming errors can cause serious problems.
  • It has fewer built-in high-level features than some modern languages.

6. C Character Set

The C character set consists of the characters that can be used in C programs.

Main Categories

  • Letters
  • Digits
  • Special characters
  • White spaces
  • Escape characters

7. Tokens in C

Tokens are the smallest meaningful units of a C program.

Main Types

  • Keywords
  • Identifiers
  • Constants
  • Strings
  • Operators
  • Special symbols

8. Keywords and Identifiers

Keywords

Keywords are reserved words that have special meanings in C.

Examples include: int, float, char, if, else, while, for, return.

Identifiers

Identifiers are names given to variables, functions and other program elements.

Rules for identifiers:
  • They should not begin with a number.
  • They may contain letters, digits and underscores.
  • They cannot be C keywords.
  • C is case-sensitive.

9. Constants

A constant is a value that does not change during program execution.

Examples

  • 10
  • 25.5
  • 'A'
  • "StudyHub"
const int age = 20;

10. Variables

A variable is a named memory location used to store a value that may change while a program is running. 

int age = 20;

float price = 25.5;

char grade = 'A';

11. Data Types in C

Data types specify the type of value that a variable can store.

Common Data Types

  • int: stores whole numbers.
  • float: stores decimal numbers.
  • double: stores more precise decimal numbers.
  • char: stores a single character.
  • void: represents the absence of a value.

12. Format Specifiers

Format specifiers tell functions such as printf and scanf what type of data is being processed.

Specifier Use
%d Integer
%f Floating-point value
%c Character
%s String

13. Operators in C

Operators are symbols used to perform operations on values and variables.

Arithmetic Operators

  • +
  • -
  • *
  • /
  • %

Relational Operators

  • ==
  • !=
  • >
  • <
  • >=
  • <=

Logical Operators

  • &&
  • ||
  • !

14. Expressions

An expression is a combination of values, variables and operators that produces a result. 

sum = a + b;

average = total / 5;

15. A Simple C Program

#include <stdio.h>

int main()
{
    printf("Hello, StudyHub!");

    return 0;
}

Explanation

  • #include <stdio.h> includes the standard input/output library.
  • main() is the main function where program execution begins.
  • printf() displays information on the screen.
  • return 0; indicates successful program completion.

16. Input and Output

Output Using printf()

printf("Welcome to C");

Input Using scanf()

int age;

scanf("%d", &age);

The ampersand is used with scanf for most ordinary variables because scanf needs the variable's memory address.

17. Statements in C

A statement is an instruction that tells the computer to perform an action.

Examples

x = 10;

printf("%d", x);

return 0;

18. The if Statement

The if statement executes a block of code when a condition is true. 

if (age >= 18)
{
    printf("Adult");
}

19. The if-else Statement

if (marks >= 50)
{
    printf("Pass");
}
else
{
    printf("Fail");
}

The first block executes when the condition is true. The else block executes when the condition is false.

20. Nested if Statements

A nested if statement is an if statement placed inside another if or else block. 

if (marks >= 50)
{
    if (marks >= 80)
    {
        printf("Excellent");
    }
}

21. switch Statement

The switch statement is useful when one expression needs to be compared with several possible values. 

switch(choice)
{
    case 1:
        printf("Add");
        break;

    case 2:
        printf("Subtract");
        break;

    default:
        printf("Invalid choice");
}

22. Loops

Loops are used to repeat a block of code.

Main Types of Loops

  • for loop
  • while loop
  • do-while loop

23. for Loop

for(int i = 1; i <= 5; i++)
{
    printf("%d\n", i);
}

The loop initializes a variable, checks a condition and updates the variable repeatedly.

24. while Loop

int i = 1;

while(i <= 5)
{
    printf("%d\n", i);

    i++;
}

25. do-while Loop

int i = 1;

do
{
    printf("%d\n", i);

    i++;

}
while(i <= 5);

A do-while loop executes its body at least once before checking the condition.

26. break and continue

break

The break statement immediately terminates a loop or switch.

continue

The continue statement skips the current iteration and moves to the next iteration.

27. Arrays

An array is a collection of elements of the same data type stored under one variable name. 

int marks[5] =
{
    70, 65, 80, 55, 90
};

Array indexing starts from zero. Therefore, the first element is at index 0.

28. Accessing Array Elements

int numbers[3] =
{
    10, 20, 30
};

printf("%d", numbers[0]);

The program prints the first element, which is 10.

29. Finding the Sum of Array Elements

#include <stdio.h>

int main()
{
    int numbers[5] =
    {10, 20, 30, 40, 50};

    int sum = 0;

    for(int i = 0; i < 5; i++)
    {
        sum = sum + numbers[i];
    }

    printf("Sum = %d", sum);

    return 0;
}

30. Strings

A string is a sequence of characters terminated by a special null character. 

char name[] = "John";

printf("%s", name);

31. String Functions

The C library provides functions for working with strings.

Common Functions

  • strlen()
  • strcpy()
  • strcat()
  • strcmp()

These functions are commonly available through the string.h header file.

32. Functions

A function is a block of code designed to perform a particular task.

Advantages

  • Reduces repetition.
  • Improves program organization.
  • Makes programs easier to test.
  • Improves code reuse.
void greet()
{
    printf("Welcome");
}

33. Function Parameters and Return Values

int add(int a, int b)
{
    return a + b;
}

Here, a and b are parameters, while the function returns an integer result.

34. Recursion

Recursion occurs when a function calls itself. 

int factorial(int n)
{
    if(n == 0)
        return 1;

    return n * factorial(n - 1);
}
Important: A recursive function must have a stopping condition, otherwise it can continue indefinitely.

35. Pointers

A pointer is a variable that stores the memory address of another variable. 

int age = 20;

int *ptr = &age;

printf("%d", *ptr);

The & operator obtains an address, while * can be used to access the value stored at that address.

36. Structures

A structure allows related variables of different data types to be grouped together. 

struct Student
{
    char name[50];

    int age;

    float marks;
};

37. File Handling

File handling allows programs to store and retrieve information from files.

Common File Operations

  • Opening a file
  • Reading from a file
  • Writing to a file
  • Appending data
  • Closing a file

38. Writing to a File

FILE *file;

file = fopen("data.txt", "w");

fprintf(file, "StudyHub");

fclose(file);

The file should be closed after completing the required operations.

39. Common Programming Errors

Syntax Errors

Errors that occur when the rules of the programming language are violated.

Runtime Errors

Errors that occur while the program is running.

Logical Errors

The program runs but produces an incorrect result.

40. Debugging

Debugging is the process of finding and correcting errors in a program.

Basic Debugging Steps

  1. Identify the error.
  2. Locate the source of the problem.
  3. Understand why it happened.
  4. Correct the code.
  5. Test the program again.

41. Characteristics of a Good Program

  • Correctness: Produces the expected result.
  • Readability: Easy for humans to understand.
  • Efficiency: Uses resources effectively.
  • Maintainability: Easy to modify.
  • Reliability: Performs consistently.
  • Portability: Can work on different systems.

42. Algorithms

An algorithm is a step-by-step procedure for solving a problem.

Example: Adding Two Numbers

  1. Start.
  2. Enter the first number.
  3. Enter the second number.
  4. Add the two numbers.
  5. Display the result.
  6. Stop.

43. Flowcharts

A flowchart is a graphical representation of an algorithm.

Common Flowchart Symbols

  • Oval – Start/End
  • Rectangle – Process
  • Parallelogram – Input/Output
  • Diamond – Decision
  • Arrow – Direction of flow

44. Preprocessor Directives

Preprocessor directives are instructions processed before the main compilation of a C program.

Example

#include <stdio.h>

The #include directive is commonly used to include header files.

45. Comments in C

Comments are notes written in source code to explain what the program does. They are ignored by the compiler.

Single-Line Comment

// This is a comment

Multi-Line Comment

/*
   This is a
   multi-line comment
*/

46. Steps in Developing a C Program

  1. Understand the problem.
  2. Analyze the requirements.
  3. Design an algorithm.
  4. Create a flowchart if necessary.
  5. Write the C program.
  6. Compile the program.
  7. Identify and fix errors.
  8. Test the program.
  9. Document the program.
  10. Maintain the program.

47. Practice Programs

Program 1: Add Two Numbers

#include <stdio.h>

int main()
{
    int a, b, sum;

    printf("Enter first number: ");
    scanf("%d", &a);

    printf("Enter second number: ");
    scanf("%d", &b);

    sum = a + b;

    printf("Sum = %d", sum);

    return 0;
}

Program 2: Check Even or Odd

#include <stdio.h>

int main()
{
    int number;

    printf("Enter a number: ");
    scanf("%d", &number);

    if(number % 2 == 0)
    {
        printf("Even");
    }
    else
    {
        printf("Odd");
    }

    return 0;
}

Program 3: Find the Largest Number

#include <stdio.h>

int main()
{
    int a, b;

    printf("Enter two numbers: ");

    scanf("%d", &a);
    scanf("%d", &b);

    if(a > b)
    {
        printf("%d is larger", a);
    }
    else
    {
        printf("%d is larger", b);
    }

    return 0;
}
