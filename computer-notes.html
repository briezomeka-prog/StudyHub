GECC 1101

Fundamentals of Computers and Office Applications

Complete study notes covering computer fundamentals, hardware, software, operating systems, internet, computer security and Microsoft Office applications.

1. Introduction to Computers

Definition: A computer is an electronic device that accepts data as input, processes the data according to instructions, stores information and produces useful output.

Computers are used in almost every area of modern life. They are used in education, banking, business, hospitals, communication, transportation, entertainment and scientific research.

Basic Computer Process

  1. Input: Data is entered into the computer.
  2. Processing: The computer manipulates the data.
  3. Output: The processed information is presented.
  4. Storage: Data and information can be saved for future use.
Remember: The basic computer cycle is Input → Processing → Output → Storage.

2. History and Generations of Computers

Computers have developed from simple mechanical calculating machines into powerful digital devices used today.

Generation Main Technology Characteristics
First Vacuum tubes Very large, expensive and produced much heat.
Second Transistors Smaller, faster and more reliable.
Third Integrated Circuits More powerful and smaller computers.
Fourth Microprocessors Personal computers became common.
Fifth Artificial Intelligence Focuses on intelligent and advanced computing.

3. Characteristics of Computers

Computers have several characteristics that make them useful for processing information.

Speed

Computers can process large amounts of data very quickly.

Accuracy

Computers can produce accurate results when given correct instructions.

Storage

Computers can store large amounts of information.

Automation

Computers can perform tasks automatically after receiving instructions.

Reliability

Computers can perform repetitive tasks consistently.

Versatility

Computers can perform many different types of tasks.

4. Types of Computers

Computers can be classified according to size, purpose and processing ability.

  • Supercomputers: Extremely powerful computers used for complex calculations.
  • Mainframe computers: Large systems used by organizations to process huge amounts of data.
  • Minicomputers: Medium-sized computers used by organizations and departments.
  • Microcomputers: Personal computers such as desktops and laptops.
  • Embedded computers: Computers built into other devices such as cars and appliances.
  • Mobile computers: Portable devices such as tablets and smartphones.

5. Computer Hardware

Hardware refers to the physical components of a computer that can be seen and touched.

Examples include:

  • Keyboard
  • Mouse
  • Monitor
  • System unit
  • Printer
  • Speakers
  • Hard disk
  • RAM
  • Motherboard
  • Processor

6. Input Devices

Input devices are hardware devices used to enter data and instructions into a computer.

Device Purpose
Keyboard Used to enter text, numbers and commands.
Mouse Used to point, select and interact with objects.
Scanner Converts physical documents into digital form.
Microphone Inputs sound into the computer.
Webcam Inputs video and images.
Touchscreen Allows users to interact directly with the screen.

7. Output Devices

Output devices present processed information to the user.

  • Monitor: Displays text, images and videos.
  • Printer: Produces information on paper.
  • Speakers: Produce sound.
  • Projector: Displays computer content on a large screen.
  • Headphones: Produce private audio output.

8. Storage Devices

Storage devices are used to save data and information for future use.

Storage Device Description
Hard Disk Drive Stores large amounts of data using magnetic storage.
SSD Fast storage device with no moving mechanical parts.
USB Flash Drive Portable storage device.
Memory Card Small storage device commonly used in mobile devices.
CD/DVD Optical storage media.

9. Computer Memory

Computer memory stores data and instructions that are currently being used by the computer.

Types of Memory

  • RAM: Temporary memory used while programs are running.
  • ROM: Permanent memory containing important instructions.
  • Cache: Very fast memory that helps the CPU access frequently used data.
Important: RAM is volatile. This means information stored in RAM is normally lost when power is turned off.

10. CPU and Its Components

The CPU (Central Processing Unit) is the main processing component of a computer. It executes instructions and performs calculations.

Main Components of the CPU

  • ALU: Performs arithmetic and logical operations.
  • Control Unit: Controls and coordinates computer operations.
  • Registers: Small, very fast storage locations inside the CPU.

11. Computer Software

Software is a collection of programs and instructions that tell computer hardware what to do.

Software can generally be divided into:

  1. System software
  2. Application software

12. System Software

System software controls computer hardware and provides a platform for application programs.

Examples

  • Windows
  • Linux
  • macOS
  • Device drivers
  • Utility programs
  • Firmware

13. Application Software

Application software is designed to help users perform specific tasks.

Application Purpose
Microsoft Word Creating and editing documents.
Microsoft Excel Working with numbers, calculations and data.
Microsoft PowerPoint Creating presentations.
Microsoft Access Managing databases.
Web browsers Accessing websites and online services.

14. Operating Systems

An Operating System (OS) is system software that manages computer hardware, software resources and provides an interface for users.

Functions of an Operating System

  • Managing files and folders
  • Managing memory
  • Managing hardware devices
  • Managing running programs
  • Providing a user interface
  • Providing security
  • Managing users

15. Windows Basics

Microsoft Windows is a graphical operating system widely used on personal computers.

Important Windows Components

  • Desktop
  • Taskbar
  • Start Menu
  • File Explorer
  • Recycle Bin
  • Settings
  • Search

Useful Keyboard Shortcuts

Shortcut Function
Ctrl + C Copy
Ctrl + V Paste
Ctrl + X Cut
Ctrl + Z Undo
Ctrl + S Save
Ctrl + P Print
Ctrl + A Select all
Alt + Tab Switch between open applications

16. Files and Folders

A file is a collection of related information stored with a name. A folder is used to organize files and other folders.

Common File Operations

  1. Create a file or folder.
  2. Rename a file or folder.
  3. Copy a file or folder.
  4. Move a file or folder.
  5. Delete a file or folder.
  6. Restore deleted files from the Recycle Bin.
Good practice: Organize files into clearly named folders and make regular backups of important information.

17. Computer Security

Computer security involves protecting computer systems, networks, programs and information from unauthorized access, damage or theft.

Basic Security Practices

  • Use strong passwords.
  • Do not share passwords unnecessarily.
  • Keep software updated.
  • Use trusted security software.
  • Avoid suspicious websites and links.
  • Back up important files.
  • Lock your computer when leaving it unattended.

18. Computer Viruses and Malware

Malware means malicious software designed to damage systems, steal information or perform unauthorized activities.

Types of Malware

  • Virus: Malicious code that can attach itself to files.
  • Worm: Malware that can spread across networks.
  • Trojan: Malicious software disguised as legitimate software.
  • Spyware: Software that secretly collects information.
  • Ransomware: Malware that can prevent access to data and demand payment.
Warning: Never open suspicious attachments or install unknown software from untrusted sources.

19. Internet and Networking Basics

The Internet is a global network of interconnected computer networks that communicate using standard protocols.

Common Network Terms

  • LAN: Local Area Network.
  • WAN: Wide Area Network.
  • Wi-Fi: Wireless networking technology.
  • Router: Connects networks and directs data traffic.
  • IP Address: An address used to identify a device on a network.
  • Browser: Software used to access websites.

20. Email

Email is an electronic method of sending and receiving messages over computer networks and the Internet.

Common Parts of an Email

  • To
  • CC
  • BCC
  • Subject
  • Message body
  • Attachment
Email etiquette: Use a clear subject, professional language and check attachments before sending an email.

21. Microsoft Word

Microsoft Word is a word-processing application used to create, edit, format, save and print documents.

Uses of Microsoft Word

  • Writing assignments
  • Creating reports
  • Creating letters
  • Creating resumes
  • Creating tables
  • Designing simple documents
  • Printing documents

22. Creating and Formatting Documents in Word

Basic Steps

  1. Open Microsoft Word.
  2. Select a blank document.
  3. Type your content.
  4. Select the text you want to format.
  5. Apply font type and size.
  6. Use bold, italic or underline where appropriate.
  7. Adjust alignment and spacing.
  8. Save the document.

Common Formatting Options

  • Bold
  • Italic
  • Underline
  • Font size
  • Font colour
  • Text alignment
  • Line spacing
  • Bullets and numbering

23. Tables in Microsoft Word

Tables organize information into rows and columns.

Steps to Insert a Table

  1. Open the Insert tab.
  2. Select Table.
  3. Choose the required number of rows and columns.
  4. Enter information into the cells.
  5. Format the table if necessary.
Tables are useful for timetables, marks, lists, comparisons and structured information.

24. Page Layout and Printing

Page layout controls how a document appears on the page.

Important Page Layout Options

  • Margins
  • Orientation
  • Paper size
  • Columns
  • Page breaks
  • Headers and footers
  • Page numbers

Printing Steps

  1. Save the document.
  2. Click File.
  3. Select Print.
  4. Select the printer.
  5. Choose pages and number of copies.
  6. Preview the document.
  7. Click Print.

25. Microsoft Excel

Microsoft Excel is a spreadsheet application used for organizing data, performing calculations, analyzing information and creating charts.

Uses of Excel

  • Calculating marks
  • Preparing budgets
  • Creating lists
  • Analyzing data
  • Preparing financial records
  • Creating charts and graphs

26. Worksheets, Rows and Columns

Excel organizes information using rows and columns.

  • Workbook: An Excel file containing one or more worksheets.
  • Worksheet: A spreadsheet page containing rows and columns.
  • Row: A horizontal arrangement of cells.
  • Column: A vertical arrangement of cells.
  • Cell: The intersection of a row and column.
  • Cell reference: The address of a cell, such as A1.

27. Excel Formulas and Functions

A formula is an expression used to perform a calculation in Excel. Formulas normally begin with an equals sign.

Examples

= A1 + B1 = A1 - B1 = A1 * B1 = A1 / B1 = SUM(A1:A10) = AVERAGE(A1:A10) = MAX(A1:A10) = MIN(A1:A10)

Common Functions

Function Purpose
SUM Adds values.
AVERAGE Calculates the average.
MAX Finds the highest value.
MIN Finds the lowest value.
COUNT Counts cells containing numbers.

28. Charts and Graphs in Excel

Charts present numerical information visually, making patterns and comparisons easier to understand.

Common Chart Types

  • Column chart
  • Bar chart
  • Line chart
  • Pie chart
  • Area chart

Basic Steps to Create a Chart

  1. Enter your data.
  2. Select the data.
  3. Click the Insert tab.
  4. Select a chart type.
  5. Choose the appropriate chart.
  6. Add a title and labels where necessary.

29. Microsoft PowerPoint

Microsoft PowerPoint is presentation software used to create and display information using slides.

Uses of PowerPoint

  • Class presentations
  • Business presentations
  • Training materials
  • Seminars
  • Project presentations
  • Educational lessons

30. Creating Presentations

Basic Steps

  1. Open PowerPoint.
  2. Select a presentation template or blank presentation.
  3. Create a title slide.
  4. Add additional slides.
  5. Enter text and information.
  6. Add suitable images or diagrams.
  7. Apply an appropriate design.
  8. Review the presentation.
  9. Save the presentation.
Presentation tip: Avoid filling slides with too much text. Use short points and explain the details verbally.

31. Slide Design and Transitions

PowerPoint allows users to improve presentations using themes, animations and slide transitions.

Important Design Principles

  • Use readable fonts.
  • Maintain good contrast.
  • Do not overcrowd slides.
  • Use images that support the topic.
  • Maintain consistent formatting.
  • Use animations carefully.
  • Keep transitions professional.

32. Microsoft Access and Database Basics

A database is an organized collection of related data that can be stored, managed and retrieved.

Important Database Terms

  • Table: Stores related data in rows and columns.
  • Record: A complete set of information about one item.
  • Field: A specific type of information.
  • Primary Key: A field used to uniquely identify records.
  • Query: Used to retrieve specific information.
  • Form: Provides a user-friendly way of entering data.
  • Report: Presents database information in a structured format.

33. Computer Ethics

Computer ethics refers to principles that guide responsible and acceptable use of computers and information technology.

Examples of Ethical Computer Use

  • Respect other people's privacy.
  • Do not access systems without permission.
  • Do not steal digital information.
  • Do not spread harmful software.
  • Respect copyright.
  • Do not use technology to harass others.
  • Use information responsibly.

34. Advantages and Limitations of Computers

Advantages

  • High processing speed.
  • Large storage capacity.
  • Accurate calculations.
  • Improved communication.
  • Automation of repetitive tasks.
  • Easy access to information.
  • Improved productivity.

Limitations

  • Computers require electricity.
  • They can be affected by malware.
  • Hardware can fail.
  • Incorrect input can produce incorrect results.
  • Users require appropriate skills.
  • Technology can create privacy and security risks.

35. Common Computer Problems and Solutions

Problem Possible Solution
Computer is slow Close unnecessary programs, restart the computer and check storage.
No Internet Check Wi-Fi, cables, router and network settings.
Printer not working Check power, paper, connection and printer settings.
Application not responding Wait, close the application or restart it.
File cannot be found Search the computer and check the correct folder.
Computer overheats Ensure proper ventilation and keep air vents clear.

42. Course Summary

Fundamentals of Computers and Office Applications introduces students to the basic concepts of computer technology and practical computer usage.

The course covers computer hardware, software, memory, storage, input and output devices, CPU operations, operating systems, file management, computer security, Internet and email.

It also develops practical skills in Microsoft Word, Microsoft Excel, Microsoft PowerPoint and basic database applications.

By the end of the course, students should be able to use computers confidently, create and manage documents, perform spreadsheet calculations, prepare presentations, organize information and apply responsible computer-use practices.
